# 나라사랑 혜택

나라사랑카드(체크) 4종 — **하나 · IBK · 신한 · KB국민** — 의 혜택을 결제 전에 빠르게 찾아보는 PWA입니다.

- **찾기**: 업종(카페·편의점·PX…)으로 찾으면 그 업종 혜택 전체를, 가맹점(스타벅스·CU…)으로 찾으면 그 가맹점 혜택만 보여주고, 금액을 넣으면 카드별 예상 할인액과 추천 카드·추천 이유·차선 카드를 알려줌
- **결제 경로**: 결과가 달라질 때만 ‘일반 PX / GS25 해군마트’, ‘매장 / 공식 앱·웹 / 간편결제’, ‘행사상품 여부’를 물어봄. 모르면 조건부 혜택을 확정 금액에 넣지 않고 따로 표시
- **결제 기록**: ‘결제 기록’을 누르면 혜택별 일·월·연 한도와 횟수, 카드 통합한도에서 차감. 한도를 다 쓰면 다른 카드를 추천 (기록은 내 카드 탭에서 확인·삭제)
- **PX 나눠 결제**: 홈 PX 화면에서 ‘한 번에 / 간단하게(최대 2회) / 최대 절약(최대 3회)’. 한 번 더 나눌 때마다 100원·500원(기본)·1,000원 이상 더 아낄 때만 나눔 (예: PX 5만원 → 하나 16,700원 + 하나 33,300원 = 11,660원)
- **계산대 모드**: 나눠 결제 조합을 단계별로 크게 보여주고, ‘결제 완료’를 누른 단계만 기록. 금액 변경(완료분 유지·남은 금액 재계산), 직전 단계 되돌리기(앱 기록만), 새로고침 후 이어하기, 조건이 바뀌면 다시 계산 안내
- **남은 한도 맞추기**: 내 카드 탭에서 카드사 앱에서 본 통합 잔여 할인액·혜택별 남은 금액/횟수를 입력. 가짜 거래 없이 ‘그 시점 남은 양 − 이후 기록’으로 계산하고, 기간이 바뀌면 효력 없음
- **즐겨찾기**: 검색 결과의 ☆로 저장(고른 결제 경로 포함), 홈 바로가기에 먼저 표시, 설정에서 순서 변경·삭제
- **섹터 / 내 카드 / 설정**: 섹터별 정렬, 카드별 전체 혜택·통합 할인한도, 보유 카드·급여 은행·적금·지난달 사용액 입력

빌드 과정 없는 정적 사이트입니다 (HTML/CSS/JS). 서버·회원가입·분석 도구가 없고, 설정·결제 기록·즐겨찾기·맞춘 한도·계산대 진행 상태는 기기의 localStorage에만 저장됩니다. 설정 화면에서 JSON(v3)으로 내보내기·가져오기 할 수 있고, 예전 v2 백업도 읽습니다. 글꼴은 시스템 글꼴을 써서 외부 요청이 없습니다.

### 추천 규칙
- **추천**: 자격·실적 조건이 모두 확인되고 이용 조건이 없는 혜택
- **조건 충족 시 예상 혜택**: 앱 결제만·행사상품만 같은 이용 조건(`ctx`)이 있는 혜택
- **확인 필요**: 현역병 여부, 마이태그 등록, 전월 실적 등 아직 모르는 조건이 있거나 출처 검증이 덜 된(`verify`) 혜택 — 추천·나눠 결제에서 제외
- PX 혜택은 PX·군마트·해군마트로 찾을 때만 나옴 (일반 GS25와 구분). 신한은 GS25 해군마트에서 PX 횟수·한도를 다 쓴 결제에 Life 편의점 20%를 대신 적용
- 나눠 결제는 후보 금액(할인율이 바뀌는 금액·건당 최대·남은 한도)을 살펴보는 탐색이라 ‘최대 N회 기준 추천 조합’으로 표시

### 후속 계획 (아직 구현 안 함)
| 항목 | 내용 | 복잡도·의존성 |
| --- | --- | --- |
| F1 예상/실제 혜택 구분 | 거래별 예상·확인 완료·미적용, 실제 지급액 수정 | 중 — 한도 차감 기준(예상 vs 실제) 결정 필요, 백업 v4 |
| F2 날짜별 미리보기 | 오늘·주말·선택 날짜 비교 | 중 — 엔진 `now` 주입은 있음, 미래 실적·한도 가정 표시 필요 |
| F3 이번 달 예정 지출 배분 | 업종별 예산을 카드에 배분 | 상 — 남은 기간 전체 최적화, 업종 수 제한해서 시작 |
| F4 상품별 금액으로 나눠 결제 | 상품 가격 묶음으로 카드 추천 | 중 — 현재 `plan`의 금액 후보를 상품 묶음 조합으로 교체, 상품 수 제한 |
| 결제 경로 확장 | 커피·배달·택시 등 다른 `ctx` 혜택에도 `route` 적용 | 하~중 — 혜택별 공식 조건 대조 필요 |
| 행사상품 일부 금액 | 편의점 결제 중 행사상품 금액만 따로 입력 | 하 |

## 실행 / 배포

```bash
python3 -m http.server 8000   # http://localhost:8000
```

서비스워커는 HTTPS(또는 localhost)에서만 동작하므로 GitHub Pages, Netlify, Vercel 등에 저장소 루트를 그대로 올리면 됩니다. 모든 경로가 상대경로라 하위 경로(`/narasarang/`)에서도 동작합니다.

## 파일 구조

| 파일 | 내용 |
| --- | --- |
| `js/data.js` | 카드·은행·섹터·혜택 데이터 (혜택 수정은 여기서) |
| `js/engine.js` | 계산 엔진 — 조건 판정, 예상 할인, 한도 차감, 검색 (화면과 분리, Node에서 테스트) |
| `js/app.js` | 화면 렌더링, 결제 기록 저장·백업 |
| `tests/run.js` | 회귀 테스트 + 데이터·아이콘·서비스워커 검증 (`node tests/run.js`, GitHub Actions에서도 실행) |
| `css/style.css` | 스타일 (라이트/다크 모드) |
| `sw.js` | 오프라인 캐시 — **앱 파일을 수정하면 `VERSION` 값을 올려야** 설치된 앱이 갱신됨 |
| `manifest.webmanifest` | PWA 설정 |
| `icons/` | 앱 아이콘 |
| `store/` | 플레이스토어 등록 자료: 아이콘(`play-icon-512.png`), 그래픽 이미지(`feature-graphic-1024x500.png`), 스크린샷 4장(1080×1920), 아이콘 원본. 앱에서는 쓰지 않음 |

## 아이콘 교체

`icons/` 폴더에 아래 파일명 그대로 덮어쓰면 됩니다. 모두 **PNG**, 정사각형.

| 파일명 | 크기 | 용도 / 규칙 |
| --- | --- | --- |
| `icon-192.png` | 192×192 | 안드로이드 홈 화면. 투명 배경 가능 |
| `icon-512.png` | 512×512 | 안드로이드 스플래시·설치 화면. 투명 배경 가능 |
| `maskable-512.png` | 512×512 | 안드로이드 적응형 아이콘. **배경을 꽉 채우고**, 로고는 가운데 지름 409px(80%) 원 안에 |
| `apple-touch-icon.png` | 180×180 | iPhone 홈 화면. **투명 불가**(배경 꽉 채움), 모서리는 iOS가 자동으로 둥글게 처리하니 직각으로 |
| `favicon-32.png` | 32×32 | 브라우저 탭 |

교체 후 `sw.js`의 `VERSION`을 올려주세요. 모든 크기는 `store/icon-master-1024.png` 한 장에서 줄여 만듭니다. 배경색은 `#1850A8`.

플레이스토어 고해상도 아이콘은 `store/play-icon-512.png`(512×512, 32비트 PNG, 배경 꽉 채움)를 올립니다. 모서리와 그림자는 스토어가 자동으로 넣습니다.
